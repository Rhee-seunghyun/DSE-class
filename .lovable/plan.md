## 목표

현재 화면에 비슷한 기능이 두 개 보이는 문제를 해결합니다:
1. **카드 바깥 상단**의 클래스 선택 드롭다운 (Select)
2. **카드 헤더 안**의 클래스명 + 표 펼침/접기 토글 버튼 (ChevronUp/Down)

→ 두 요소를 **하나의 드롭다운**으로 합쳐 **카드 헤더 안**에 배치합니다.

## 변경 내용 (`src/pages/MyClass.tsx`)

### 1. 카드 바깥의 Select 블록 제거
- 라인 310~340의 "Class List" 영역 삭제
- 단, 로딩 상태 / "클래스 없음" 빈 상태 메시지는 카드 바깥에 그대로 유지 (선택할 카드가 없으므로)

### 2. 카드 헤더 내부의 토글 버튼을 Select로 교체
- 라인 346~353의 `<Button>` (날짜 + 제목 + Chevron 토글) → `<Select>` 로 교체
- Select 옵션: 기존과 동일하게 `{날짜} · {제목}` 포맷
- 너비: `w-full lg:w-auto lg:min-w-[280px]` (헤더 좌측에서 우측 버튼 그룹과 같이 한 줄 구성)

### 3. 표 펼침/접기(`isTableVisible`) 기능 제거
- 토글 버튼이 사라지므로 `isTableVisible` state와 조건부 렌더링 삭제
- `<CardContent>` 의 `StudentTable` 은 항상 렌더링

### 4. 카드 렌더링 조건 변경
- 현재는 `selectedLecture` 가 있을 때만 카드 렌더링
- 변경: **lectures가 1개 이상이면 카드 렌더링**, 카드 헤더에 Select가 항상 보이도록 함
- 우측 액션 버튼들(통계/신청서/질문/자료/Staff)은 `selectedLecture` 가 있을 때만 표시 (안전장치)
