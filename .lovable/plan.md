## 확인한 점
- 현재 프로젝트 코드의 `MyClass`에는 숨김/접기 상태가 없고, 클래스 선택용 `Select`만 남아 있습니다.
- 게시된 JS 파일에도 `클래스를 선택하세요`가 포함되어 있고, 예전 숨김 관련 코드(`isTableVisible`, `Collapsible`)는 확인되지 않았습니다.
- 따라서 단순 새로고침 문제가 아니라, 배포 환경에서 Radix `Select` 포털/캐시/이전 UI 인식이 섞여 사용자가 여전히 숨김 토글처럼 경험하는 상태로 보입니다.

## 수정 계획
1. `MyClass`의 클래스 선택 UI를 Radix `Select`에서 브라우저 기본 `<select>` 기반 선택기로 교체합니다.
   - 옵션 목록이 포털 레이어에 의존하지 않아 배포본에서도 안정적으로 열립니다.
   - 클릭 동작이 표 숨김/펼침처럼 보일 여지를 제거합니다.

2. 카드 헤더 안에 클래스 선택기를 명확히 고정합니다.
   - 선택기 라벨은 `클래스 선택`으로 표시합니다.
   - 선택 값은 `날짜 · 클래스명` 형태로 유지합니다.
   - 표 영역은 선택된 클래스가 있을 때 항상 보이도록 유지합니다.

3. 선택 상태 로직을 보강합니다.
   - 첫 로딩 시 첫 클래스를 자동 선택합니다.
   - 현재 선택된 클래스가 목록에서 사라진 경우에만 첫 클래스로 재설정합니다.
   - 사용자가 선택한 클래스는 데이터 새로고침 후에도 불필요하게 바뀌지 않게 합니다.

4. 배포 전 검증 포인트
   - 프리뷰에서 클래스 목록이 드롭다운으로 열리는지 확인합니다.
   - 선택 변경 시 아래 수강생 표가 해당 클래스로 바뀌는지 확인합니다.
   - 숨김/펼침처럼 동작하는 버튼이 더 이상 없는지 확인합니다.

## 배포 안내
- 구현 후에는 최신 프론트엔드가 반영되도록 Publish 창에서 `Update`가 필요합니다.
